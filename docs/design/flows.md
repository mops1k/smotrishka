# Переходы и состояния

Модель состояния макета и все правила переходов. В приложении это навигация Compose + флаги
экрана.

## Состояние экрана

| Понятие | Значения | Что задаёт |
|---|---|---|
| `view` | `tv`, `favorites`, `recent`, `settings` | раздел; определяет заголовок шапки, наличие плашки категорий и шапки списка |
| `category` | `Все каналы`, `Новости`, `Кино`, `Музыка`, `Спорт`, `Детям` | фильтр списка в «Телеканалах» |
| `query` | строка | фильтр по названию канала (из поиска) |
| `selectedId` | id канала | выбранная карточка |
| `favorites` | набор id | избранное, стартово `{2, 3, 5}` |
| `searchOpen` | да/нет | оверлей поиска |
| `programOpen` | да/нет | разворот телепрограммы в «Телеканалах» |
| `playerId` | id канала или `null` | открыт ли плеер и на каком канале |
| `playerArchive` | да/нет | плеер в архивном режиме |
| `playerLoading` | да/нет | экран загрузки плеера (1.5 с в макете) |
| `osdVisible` | да/нет | видно ли управление в плеере |
| `playerPanel` | `null`, `recents`, `programme` | какая панель открыта в плеере |
| `playing`, `muted` | да/нет | иконки паузы и звука |
| `seekOffset` | секунды | визуальный сдвиг полосы от ±10 с |
| `aspectIndex` | 0…3 | режим кадра |
| `toast` | строка или пусто | текущее подтверждение |
| `guideDialog`, `guideUrl`, `guides` | — | добавление гидов XMLTV |
| `buffer`, `quality`, `retries`, `audioLanguage`, `dataSaver`, `epgWindow`, `archiveDepth`, `directStream` | значения настроек | карточки настроек |

## Список каналов

Фильтр списка = раздел ∧ категория ∧ подстрока поиска:

- раздел «Избранное» → только `favorites`;
- «Недавние» → без дополнительного фильтра (пробел, см. README);
- «Телеканалы» → фильтр по `category`;
- поиск → фильтр по названию.

Счётчик в шапке панели показывает длину результата, слово склоняется (1 канал / 2 канала /
8 каналов).

## Таблица переходов

| Действие | Результат |
|---|---|
| Клик по пункту меню | `view` = пункт, `category` сбрасывается в «Все каналы», плашка и шапка списка появляются только для `tv` |
| Клик по бренду | `view` = `tv` |
| Клик по категории | `category` = выбранная, список и шапка обновляются |
| Клик по строке канала | `selectedId` = канал, правая карточка обновляется |
| Клик по сердцу в карточке | канал добавляется/убирается из `favorites`; в «Избранном» список пересобирается |
| Клик по лупе | `searchOpen` = да, фокус в поле |
| Ввод в поиске | список фильтруется по подстроке, счётчик обновляется |
| Esc / «назад» в поиске, клик мимо | `searchOpen` = нет, фильтр по подстроке сбрасывается вместе с запросом |
| Клик «Телепрограмма канала» | `programOpen` = да: панель расширяется, показывается сетка передач |
| Клик «Свернуть» / Esc | `programOpen` = нет: возвращается карточка |
| Клик по прошедшей передаче (с архивом) | открывается плеер в архивном режиме на этом канале |
| Клик по прошедшей передаче без архива | подсказка «Архив недоступен для этого канала»; строка имеет класс `no-archive` (без hover), плеер не переключается, архив не включается |

## Онбординг

| Событие | Результат |
|---|---|
| Запуск без источника | Онбординг целиком, без каркаса |
| Смена способа подключения | Поля другого типа, фокус в первое поле, ошибка сбрасывается |
| «Подключить» с корректными данными | Загрузка 1,6 с → «Телеканалы» + тост «Источник подключён, каналы загружены» |
| «Подключить» с некорректными данными | Плашка ошибки под формой, фокус остаётся в форме |
| «Отмена»/Esc при входе из настроек | Возврат в «Настройки» |
| Успех при входе из настроек | «Телеканалы», строка «Источник» показывает новую подпись |
| Клик по текущей передаче | открывается плеер в прямом эфире |
| Клик по будущей передаче | тост ««Название» начнётся в HH:MM», плеер не открывается |
| Клик «Смотреть» | `playerId` = выбранный канал, `playerArchive` = нет, `playerLoading` = да |
| 1.5 с в плеере | `playerLoading` = нет, `osdVisible` = да |
| Клик «Программа канала» в OSD | `playerPanel` = `programme`, фокус на текущей передаче |
| Клик «Недавние каналы» в OSD | `playerPanel` = `recents` |
| Клик по каналу в панели «Недавние» | `playerId` = выбранный канал, панель закрывается, плеер остаётся |
| Клик по текущей передаче в панели программы | панель закрывается |
| Клик по прошедшей передаче в панели программы | `playerArchive` = да, позиция ≈ `0:54`, панель закрывается |
| Клик по будущей передаче в панели программы | тост со временем начала |
| «Назад»/Esc в панели, клик мимо карточки | панель закрывается, плеер остаётся |
| «Назад»/Esc в плеере без панели | плеер закрывается, возвращается раздел, из которого пришли |
| Клик по экрану при скрытом OSD | OSD показывается |
| Клик по пустому месту при видимом OSD | OSD скрывается |
| 5 с без действий | OSD скрывается сам (кроме случая открытой панели) |
| ⏪/⏩ 10 с | полоса сдвигается на 10 с, границы зажаты началом и концом передачи |
| ⏯ | меняется иконка и признак `playing`; воспроизведения нет |
| Динамик | меняется иконка `muted` |
| «Режим кадра» | следующий из четырёх по кругу, подсказка на 1.6 с |
| Боковая стрелка ‹ / › | канал предыдущий/следующий по списку, OSD и полоса обновляются |
| «В эфир» в архивном режиме | `playerArchive` = нет, возвращается прямой эфир |
| Действия в настройках («Сменить», «Выбрать файл», «Вернуть», «Загрузить заново») | разовый тост |
| Выбор варианта в настройках | значение меняется, активный вариант подсвечивается |
| Переключатель «Экономия трафика» | включён/выключен |
| «Добавить» у гидов | диалог; пустой адрес — тост «Введите адрес гида»; иначе гид в списке + «Гид добавлен» |
| «Удалить» у гида | гид убирается, тост «Гид удалён» |
| Esc / «назад» в диалоге гида | диалог закрывается |

## Приоритет закрытия (Esc / системная «назад»)

1. открыт диалог гида → закрыть диалог;
2. открыт поиск → закрыть поиск;
3. открыта панель плеера → закрыть панель;
4. открыт плеер → закрыть плеер;
5. открыт разворот телепрограммы → свернуть;
6. иначе — обычный системный «назад».

## Таймеры

| Таймер | Значение |
|---|---|
| Экран загрузки плеера | 1.5 с |
| Автоскрытие OSD | 5 с без действий |
| Подсказка режима кадра | 1.6 с |
| Тост | 2.4 с |

## Клавиатура и фокус

Макет повторяет ТВ-сценарий:

- **Стрелки** — пространственная навигация: из текущего элемента берётся ближайший в нужную
  сторону; вес = расстояние по оси движения + 2.4 × расстояние по поперечной оси, побеждает
  минимум. В приложении эту роль выполняет `focusProperties`/ручная обработка `KeyEvent`
  (в `PlayerScreen` уже реализовано вручную).
- **Enter/центр** — активация кнопки.
- Во всех интерактивных элементах есть видимый фокус: `outline 3px #d1bcff`, отступ 3,
  внешнее свечение `rgba(169,135,255,.18)`.
- В поиске стрелки не перехватываются, пока фокус в поле ввода.
- Esc и «назад» подчиняются приоритету закрытия выше.

## Пустые и пограничные состояния

| Случай | Поведение |
|---|---|
| Ничего не найдено (поиск или категория) | пустое состояние списка, карточка справа остаётся на последнем выбранном канале |
| У канала нет архива | пилюля «Архив» не выводится, колонка бейджей остаётся пустой |
| У канала нет гидов | текст «Гиды не добавлены» |
| Передача закончилась (полоса дошла до конца) | «передача закончилась» вместо «осталось N мин» |
| Позиция перемотки на границе | зажата 0…100 % |
