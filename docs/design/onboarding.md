# Онбординг: подключение источника

Первый экран приложения: пока источник каналов не подключён, смотреть нечего. Один экран на все
способы подключения — тип выбирается чипами сверху, поля меняются под него.

Снимки экрана — [`screens/onboarding/`](screens/onboarding/), детали — в
[`components.md`](components.md#онбординг).

## Когда показывается

| Событие | Что происходит |
|---|---|
| Первый запуск, источника нет | Экран целиком, без каркаса: сайдбара, шапки и списка каналов на экране нет |
| «Настройки» → «Источник каналов» → «Сменить» | Тот же экран поверх работы: поля подставлены значениями активного источника, внизу появляется «Отмена» |
| Подключение успешно | Экран закрывается, открываются «Телеканалы», тост «Источник подключён, каналы загружены» |
| Источник уже есть | Экран при запуске не показывается |

Вход из настроек: поля подставлены значениями активного источника, внизу две кнопки —
[`07-from-settings.jpg`](screens/onboarding/07-from-settings.jpg).

## Способы подключения

Чипы в один ряд с переносом, зазор 8. Активный — светлая плашка `#f0ecfa` с тёмным текстом,
остальные — `var(--panel)` с рамкой. Переключение способа подставляет первое поле в фокус.

| Чип | Поля | Плейсхолдеры | Тип в приложении | Снимок |
|---|---|---|---|---|
| Ссылка M3U | «Адрес плейлиста» | `http://example.com/list.m3u` | `PlaylistSource.M3uUrl(url)` | [`01-m3u.jpg`](screens/onboarding/01-m3u.jpg) |
| Xtream | «Сервер», «Логин», «Пароль» + кнопка «Скрыть/Показать» | `http://example.com:8080`, `логин провайдера`, `пароль провайдера` | `PlaylistSource.Xtream(server, username, password)` | [`02-xtream.jpg`](screens/onboarding/02-xtream.jpg) |
| Код iedem.tv | «Код из личного кабинета» | `например, 4821 7304` | `PlaylistSource.IedemCode(code)` | [`03-iedem.jpg`](screens/onboarding/03-iedem.jpg) |
| Плейлист из файла | плашка файла и кнопка «Выбрать файл» | — | `PlaylistSource.File(uri, name)` | [`04-file.jpg`](screens/onboarding/04-file.jpg) |

Поле: подпись 10/600 `#8b92a0`, бокс `min-height 46`, радиус 12, фон `#0d1118`, рамка
`var(--line)`; в фокусе рамка `rgba(169,135,255,.6)` и свечение `0 0 0 3px rgba(169,135,255,.16)`.
Ввод — 13 px, плейсхолдер `#565e6c`.

Плашка файла: `min-height 74`, радиус 14, пунктирная рамка, внутри имя файла 12/600 и подпись
9/`var(--muted)` «M3U или M3U8 с устройства или из облака», справа кнопка «Выбрать файл».
Состояния подписи: «Файл не выбран» → «Выбран файл: list.m3u».

## Состояния

| Состояние | Что меняется | Снимок |
|---|---|---|
| Обычное | Поля активны, внизу «Подключить», подсказка по пульту | [`01-m3u.jpg`](screens/onboarding/01-m3u.jpg) |
| Загрузка | Поля гаснут до 45 % и не принимают ввод, кнопка заменяется спиннером и текстом «Загружаем каналы…», подсказка меняется на «Проверяем источник и загружаем каталог» | [`06-loading.jpg`](screens/onboarding/06-loading.jpg) |
| Ошибка | Под формой появляется плашка: круг с «!» и текст причины, рамка и фон `#e76983` с прозрачностью | [`05-error.jpg`](screens/onboarding/05-error.jpg) |
| Успех | Экран закрывается, открывается список каналов, тост о подключении | [`01-channels.jpg`](screens/01-channels.jpg) |

Тексты ошибок в макете (проверка формата, без сети):

- «Укажите адрес плейлиста» — поле M3U пустое;
- «Не удалось загрузить плейлист: проверьте адрес» — адрес без `http://` или `https://`;
- «Укажите сервер и логин» — в Xtream не заполнены сервер или логин;
- «Укажите код из личного кабинета iedem.tv» — пустой код;
- «Выберите файл плейлиста» — файл не выбран.

В приложении текст ошибки приходит из состояния `OnboardingUiState.Error(reason)` и выводится тем
же местом — под формой, без диалогов, чтобы причина была видна с дивана.

## Пульт и клавиатура

- Своего экранного набора в дизайне нет: с пульта открывается системная клавиатура устройства —
  по получению фокуса или по OK/Enter, потому что на части приставок фокус её не поднимает.
- «Далее» переводит фокус на следующее поле, «Готово» отправляет форму: возвращаться к кнопке не
  нужно.
- Фокус в первое поле ставится только при смене способа подключения; при открытии экрана
  клавиатура не выезжает сама.
- Поле прокручивается так, чтобы не уйти под клавиатуру, занявшую полэкрана.
- Подсказка под формой: «OK — клавиатура · Далее — следующее поле · Готово — подключить».
- В макете поля — обычные `input`, поэтому проверять можно с клавиатуры компьютера: Enter
  отправляет форму, Tab ходит по элементам, Esc закрывает экран только если он открыт из настроек.

## Правая колонка «Как это работает»

Три шага: 01 «Выберите способ подключения — поля появятся под ним», 02 «Введите данные: с пульта
откроется системная клавиатура», 03 «Каталог загрузится сам, каналы появятся в списке». Номера
10/800 акцентом, текст 11/`#98a0ae`. Блок добавлен дизайном — в приложении его нет; он объясняет
первый запуск и заполняет правую часть карточки. Кандидат на упрощение или удаление, если экран
покажется перегруженным.

## Переходы

| Событие | Результат |
|---|---|
| Запуск без источника | Онбординг |
| Смена способа подключения | Поля другого типа, фокус в первое поле, ошибка сбрасывается |
| «Подключить», данные корректны | Загрузка 1,6 с → «Телеканалы» + тост |
| «Подключить», данные некорректны | Ошибка под формой, фокус остаётся в форме |
| «Отмена» или Esc (вход из настроек) | Возврат в «Настройки» |
| Успех при входе из настроек | «Телеканалы», строка «Источник» показывает новую подпись |
| Перезагрузка приложения | Снова онбординг — сохранённого источника у макета нет |

## Маппинг на Compose

| Макет | Compose |
|---|---|
| Карточка по центру | `Surface`/`Column` с фоном `surface` и `RoundedCornerShape(24.dp)`, внутри `Row` с весами 1f / 256.dp |
| Чипы | `FlowRow` + `FilterChip` (как сейчас в приложении) |
| Поле с подписью | `OutlinedTextField(label = { Text(...) }, singleLine = true)` |
| Кнопка показа пароля | `trailingIcon` у поля пароля — в приложении сейчас отсутствует |
| Плашка файла | `Text` с именем + `Button` + `rememberLauncherForActivityResult(OpenDocument)` |
| Загрузка | `CircularProgressIndicator` + `Text("Загружаем каналы…")` вместо кнопки |
| Ошибка | `Text(color = MaterialTheme.colorScheme.error)` под формой |
| «Подключить» | `Button` |
| Правая колонка | Новый блок; если оставляем — `Column` с тремя парами «номер + текст» |

Ограничение ширины `widthIn(max = 720.dp)` и отступы 32/24 сохраняются как в приложении.

## Чего в макете нет

- Системного проводника: «Выбрать файл» подставляет демо-имя `list.m3u`.
- Сети: задержка 1,6 с и переход к каналам — заглушка, реального разбора плейлиста нет.
- Проверки логина Xtream и кода iedem по сети — только проверка заполненности.
- Ошибок провайдера: «в плейлисте нет каналов», «неверный логин», «сервер не отвечает» — в макете
  их нет, в приложении они приходят текстом причины из ViewModel.
