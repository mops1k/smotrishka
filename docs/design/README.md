# Дизайн-спецификация редизайна SmotrishkaTV

Документ описывает готовый макет редизайна интерфейса настолько подробно, чтобы в следующей
сессии его можно было перенести в приложение (Compose) без доступа к самому макету.

Макет — экспорт Figma Make (Vite + React + TypeScript), лежит рядом с репозиторием:
`/home/mops1k/Development/smotrishka-redesign`, запуск —
`pnpm exec vite --host 0.0.0.0 --port 5180 --strictPort`, предпросмотр
`http://localhost:5180/`. Исходники макета: `src/App.tsx` (весь интерфейс) и `src/index.css`
(все стили).

## Границы: что из макета — дизайн, а что — заглушка

Переносится всегда **вид, размеры, тексты и поведение**. Не переносится реализация макета:
мок-данные, React-состояние, ручная спейшиал-навигация вместо навигации Compose.

Заглушки макета, которые в приложении должны стать настоящими:

- **Воспроизведения нет**. Полотно плеера — статичная «эфирная» картинка (градиенты, сетка,
  логотип-вотермарк). В приложении на этом месте `PlayerView`/`AndroidView` с реальным потоком.
- **Данные каналов и передач захардкожены** (8 каналов, 6 категорий, расписание из 7 передач).
  В приложении — Room/плейлист и EPG.
- **Действия настроек показывают тост**, а не выполняют работу: «Сменить источник», «Выбрать
  файл», «Вернуть», «Загрузить заново», добавление гида.
- **Гиды XMLTV** добавляются без сетевой проверки адреса.
- **Поиск** фильтрует локальный список по подстроке, без дебаунса и сетевых запросов.

Известные пробелы (в макете не нарисовано, для переноса нужно решение):

1. «Недавние» в основном экране показывают все каналы — фильтра недавно смотренных нет ни в
   макете, ни в приложении.
2. Экраны ошибок плеера — «Поток недоступен» (с выходом назад) и ошибка архива с кнопкой
   «Перейти к прямому эфиру» — в макете отсутствуют, хотя в приложении есть.
3. Состояние «Проблемы с подключением: не удаётся получить поток» (плашка вверху плеера) не
   нарисовано.
4. Панель «Недавние каналы» в плеере зависит от истории просмотров; в макете список
   фиксированный.

## Исправлено в макете по итогам ревью

- **Прошедшая передача канала без архива** больше не выдаёт тост «начнётся в HH:MM»: строка
  получает класс `no-archive` (обычный курсор, без hover-подсветки), клик показывает подсказку
  «Архив недоступен для этого канала», архив не включается и плеер не переключается. Снимки:
  [`no-archive-main-toast.jpg`](screens/components/no-archive-main-toast.jpg),
  [`archive-past-without-archive.jpg`](screens/components/archive-past-without-archive.jpg).

## Глоссарий

- **Каркас (`shell`)** — постоянные части: сайдбар, шапка контента.
- **Панель** — крупный блок-поверхность с рамкой и радиусом 20 (`channel-panel`,
  `preview-panel`, `settings-card`).
- **OSD** (on-screen display) — управляющий слой поверх видео: верхняя и нижняя полосы.
- **Оверлей** — слой поверх экрана/видео с затемнением фона: панель плеера, поиск, диалог.
- **Бейдж** — пилюля 8 px uppercase: «АРХИВ». Бейдж «Эфир» из первой версии макета удалён.
- **Разворот телепрограммы** — состояние раздела «Телеканалы», в котором правая панель
  расширяется и показывает сетку передач.

## Чек-лист приёмки переноса

Проверяется на устройстве (пульт + тач), по одному пункту:

1. Сайдбар: 4 раздела, активный с левой акцентной полосой, футера с профилем и «Онлайн» нет.
2. Шапка: заголовок раздела меняется, строки над заголовком нет, поиск и часы на месте.
3. «Телеканалы»: плашка категорий и шапка списка видны только в этом разделе.
4. «Избранное» и «Недавние»: без плашки и шапки, список начинается сразу с каналов.
5. Строка канала: время и полоса прогресса стоят в одной вертикали у всех строк, бейдж архива
   не сдвигает колонки.
6. Карточка канала: логотип, категория, название, избранное, «Сейчас», прогресс, кнопка
   «Телепрограмма канала», «Смотреть», «Далее в».
7. Разворот телепрограммы: панель расширяется, список передач с «Архив»/«Сейчас», «Свернуть»
   и Esc возвращают карточку.
8. Настройки: 12 пунктов из `PlayerSettingsStore` разложены по четырём карточкам, счётчики и
   варианты совпадают с приложением.
9. Плеер: открывается из «Смотреть», OSD гаснет сам и возвращается по действию, Esc и «Назад»
   выходят в список.
10. Панели плеера: «Недавние» и «Телепрограмма» — карточка поверх видео, фон и OSD видны
    вокруг, фокус при открытии программы — на текущей передаче.
11. Архив: «АРХИВ» и «В эфир» в шапке OSD, строка «воспроизведение m:ss».
12. Фокус: обход пультом по всем интерактивным элементам, видимый outline, никаких «провалов»
    фокуса между панелями.
13. Онбординг: показывается на первом запуске без каркаса, четыре способа подключения меняют
    поля, ошибка выводится под формой текстом, загрузка заменяет кнопку спиннером.
14. Онбординг из настроек: «Источник» → «Сменить» открывает его с подставленными значениями,
    «Отмена» и Esc возвращают в настройки, успех ведёт к каналам.
15. Онбординг и клавиатура: при открытии экрана клавиатура не выезжает, при смене способа фокус
    уходит в первое поле, «Далее» и «Готово» работают с пульта.
