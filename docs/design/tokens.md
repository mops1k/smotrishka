# Токены дизайна

Все значения сняты из `src/index.css` макета. Размеры — в CSS-пикселях макета (сетка 1600×900).

## Масштаб при переносе

Макет нарисован на 1600×900. Приложение — Android TV, ориентир 1920×1080.

- При `mdpi` на ТВ **1 px макета ≈ 1 dp** — удобно брать числа из документа как есть.
- Для макета, растянутого до 1920, линейные размеры умножаются на 1.2; проверять на устройстве,
  потому что шрифты на ТВ читаются с дивана и допускают округление вверх.

## Поверхности и фон

- Фон приложения: `var(--bg)` + радиальное свечение
  `radial-gradient(circle at 82% 7%, rgba(95,63,165,.12), transparent 32%)`.
- Панель (`.channel-panel`, `.preview-panel`, `.settings-card`): фон
  `rgba(17,21,30,.82)`, рамка `1px var(--line)`, радиус 20, `overflow: hidden`.
- Карточка плеера-панели: фон `rgba(17,21,30,.84)`, рамка `rgba(255,255,255,.12)`, радиус 20,
  тень `0 30px 90px rgba(0,0,0,.55)`, `backdrop-filter: blur(18px)`.
- Диалог поиска: фон `#151a24`, рамка `rgba(255,255,255,.12)`, радиус 17, тень
  `0 25px 80px rgba(0,0,0,.5)`.

## Сетка и отступы

- Макет: 1600×900, сайдбар 236, контент — остальное.
- Сайдбар: `padding: 31px 20px 25px`, бордер справа, `backdrop-filter: blur(20px)`.
- Меню: отступ сверху 57, зазор между пунктами 8, пункт `min-height 52` / `padding 0 15`.
- Контент: `padding: 30px 42px 38px`, `max-width: 1700px`.
- Шапка: отступ снизу 29 (17 в узком режиме).
- Плашка категорий: `padding: 2px 2px 14px`, зазор 8, кнопка `10px 18px`, радиус 11.
- Основная сетка: `grid-template-columns: minmax(480px,1.15fr) minmax(350px,.85fr)`, зазор 25.
  Развёрнутая телепрограмма: `minmax(340px,.68fr) minmax(540px,1.32fr)`.
- Шапка панели списка: высота 69, `padding 0 22`.
- Список каналов: `padding: 9px`, `max-height: calc(100vh - 226px)`, скролл.
- Строка канала: `min-height 67`, `padding 7px 11px`, зазор 12, колонки
  `43px | minmax(150px,1fr) | 92px | 105px | 18px`.
- Карточка канала: визуал `min-height 230`, копия `padding 19px 21px 21px`, панель
  `min-height 533`.
- Настройки: страница `max-width 1100`, карточка `padding 23`, сетка двух карточек
  `gap 17 / margin-top 17`, две колонки в карточке «Плеер» — `gap 22`.
- Плеер: OSD `padding 24px 32px 26px`, нижний блок `padding-inline 56`, кнопки 43, главная
  кнопка 56, зазор в ряду управления 26, боковые стрелки 46 на `bottom: 148`.
- Панель плеера: оверлей `padding 96px 40px 130px`, карточка ширина `min(900px, 100%)`,

## Фокус

Единое правило макета:

```css
button:focus-visible {
  position: relative; z-index: 5;
  outline: 3px solid #d1bcff; outline-offset: 3px;
  box-shadow: 0 0 0 6px rgba(169,135,255,.18);
}
```

У главной кнопки плеера `outline-color: white`. В приложении это аналог
`Modifier.focusable()` + `focusRequester` с рамкой того же цвета и толщины.
